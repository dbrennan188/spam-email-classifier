
# Spam Email Classifier

A full-stack spam email classification application
built using React, FastAPI and machine learning.

## Features

- Classifies emails as Spam or Ham
- Displays prediction confidence
- Animated circular confidence indicator
- React frontend connected to a FastAPI backend

## Technologies

- React
- Axios
- FastAPI
- Scikit-learn
- Python

## Running the Backend

cd backend
pip install -r requirements.txt
fastapi run

## Running the Frontend

cd frontend/spam-classifier
npm install
npm run dev
